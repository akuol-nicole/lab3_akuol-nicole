## About the Project
This lab analyzes a Twitter dataset using Python and a Bash script. 
Per the assignment rules, all sorting and finding the maximum value were implemented manually without using Python's built-in `sort()`, `sorted()`, or `max()` functions.

## Files
- `data-detective.py`: Cleans the tweets, finds the post with the highest likes, sorts posts by likes using Bubble Sort, and filters posts by keyword.
- `feed-analyzer.sh`: A shell script using command line tools to find the 5 most active users.
- `twitter_dataset.csv`: The Twitter dataset from Kaggle.
- `Readme.md`: Instructions and project explanation.

## How to Run

Run the Python program:
```bash
python3 data-detective.py
